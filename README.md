A Python program that writes one one-line AI excuse for breaking production to `/output/entry.txt`: "I fixed the memory leak by deleting the database. There is nothing left to leak." The joke is fixing a leak by deleting the whole database — technically nothing leaks anymore, because there is nothing left.

## Run it

```sh
python3 main.py
```
